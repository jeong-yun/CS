## 🗺️ 전체 로드맵 (Table of Contents)

### 1. Cloud & Infrastructure(클라우드 및 인프라)
* **[Perf]ZK Hardware Accelerator:** 영지식 증명(ZKP) 및 zkML 구동 시 발생하는 막대한 수학적 연산 병목을 해결하기 위해, GPU나 전용 반도체(FPGA/ASIC)를 활용하여 증명 생성 속도를 혁신적으로 끌어올리는 하드웨어 기반 성능 최적화 기술. ※ ICICLE 편입
* **[Gov]DePIN-based Multi-Prover Network(ComputeFi):** 빅테크의 중앙화 클라우드(AWS 등)에 의존하지 않고, 전 세계 독립적인 GPU/ASIC 제공자들을 토큰 경제(ComputeFi)로 묶어 막대한 암호학적 연산(ZKP 등)을 분산 처리하는 다중 증명 인프라 네트워크.
* **[Perf]Zero-Copy Streaming Parsing:** 들어온 바이트 스트림을 새 메모리에 복사하지 않고 원본 버퍼의 주소·길이 포인터만으로 실시간 파싱해, 초당 수천만 건의 대용량 로그를 메모리 복사 비용 없이 처리하는 고성능 데이터 전처리 기술.
* **[Perf]Watermark-based Streaming Time-Series Alignment & Sliding Window:** 분산 환경에서 지연·장애로 뒤섞여 들어오는 대규모 시계열 스트림을 '워터마크'라는 시간적 기준선으로, 허용 지연 한도 내에서 실시간 정렬하고 정확한 시간 창(Window) 단위로 집계하는 인프라 파이프라인 최적화 기술.
* **[Perf]Event Sequence Matching / CEP:** DB 엔진 내부에서 상태 머신을 돌려, 시간 창 안에서 순서대로 발생한 이벤트 체인을 셀프 조인 없이 단 한 번의 칼럼 스캔으로 판정·집계하는 초고속 시퀀스 분석 기법(대표: windowFunnel, sequenceMatch).
* **[Perf]Distributed Event Streaming Platform:** 다수의 발행자가 쏟아내는 대규모 이벤트(보안 로그 등)를 유실 없이 실시간 수집하기 위해, 데이터를 여러 파티션으로 쪼개 분산 처리하고 서버 장애 시에도 끊김 없이 소비자(분석 엔진)로 흘려보내는 범용 분산 스트리밍 인프라 기술.
* **[Perf]DB-Native Streaming Ingestion via Block-based Micro-batching:** 무거운 로그 가공 미들웨어 없이 분석 DB(대표적으로 ClickHouse)가 스트리밍 소스(Kafka 등)에서 데이터를 직접 소비한 뒤, 메모리에서 거대한 블록 단위로 뭉쳐 디스크에 일괄 저장(At-least-once)함으로써 파트 폭발·디스크 I/O 병목을 제거하는 내장형 스트리밍 수집 기술.
* **[Perf]Dead Letter Routing & Exception Handling for Streaming Ingestion:** 실시간 로그 수집 중 포맷 오염·파싱 에러를 유발하는 불량 데이터 유입 시, 전체 인제스션 파이프라인의 중단 없이 에러 메시지만 전용 데드레터 싱크(DLQ)로 실시간 우회·격리하여 시스템 무중단 가동을 확보하는 내결함성 인프라 기술(대표 구현: ClickHouse kafka_handle_error_mode).
* **[Perf]Dead Letter Log Automated Backfill & Replay Pipeline:** 에러로 DLQ에 격리됐던 불량 로그를 자동으로 정제·보정해 원본 타임스탬프(Event Time)와 순서를 유지한 채 실제 물리 스토리지로 멱등하게 재생(Replay)하여, 데이터 유실과 타임라인 공백을 막는 데이터 복구·백필 인프라 기술(대표 구현: ClickHouse).
* **[Perf]Distributed Time-Series Sequence Matching & Memory Optimization:** 대규모 분산 샤드에 흩어진 로그로 시퀀스 분석을 수행할 때, 식별자 기준으로 데이터를 코로케이션해 각 샤드가 로컬에서 연산을 완결하고 코디네이터는 결과만 취합(병합 생략)하며, 메모리 초과 시 디스크 스필로 안정화하여 OOM 없이 페타바이트급 시퀀스 매칭을 가능케 하는 분산 인프라 최적화 기술(대표 구현: ClickHouse).
* **[Perf]Bitmap Compression-based Sliding Window Aggregation:** 실시간 시계열 스트림 분석 시 윈도우 내부에 누적되는 원본 데이터로 인한 메모리 폭발(OOM)을 막기 위해, 상태를 비트맵(Roaring Bitmap)으로 압축하고 서브 버킷을 비트 논리합(OR)으로 롤업해 초고속으로 통계를 내는 인프라 최적화 기술.
* **[Perf]Multi-Dimensional Projection & Transparent Query Routing:** 단일 정렬 키 구조의 검색 지연을 극복하기 위해, 원본은 그대로 둔 채 다르게 정렬·집계된 숨겨진 복제본(프로젝션)을 파트 내부에 만들어 두고, 사용자의 기존 쿼리를 옵티마이저가 가장 빠른 복제본으로 알아서 우회시켜주는 스토리지 최적화 기술.
* **[Perf]In-Memory Micro-batch Streaming Ingestion:** 잦은 소량 인서트를 메모리에 임시 버퍼링해 크기/시간 단위 마이크로배치로 묶어 디스크에 일괄 기록함으로써, 파트 파편화(Too Many Parts)와 쓰기 증폭을 차단하는 스트리밍 적재 최적화 패턴(최신 ClickHouse는 명시적 Buffer 엔진 대신 async_insert 권장).
* **[Perf]Data Partitioning & Multi-stage Columnar Compression in Distributed OLAP Systems:** 데이터를 의미 단위로 파티셔닝해 쿼리 스캔 범위를 좁히고, 컬럼 타입 특성에 맞춘 1차 특수 인코딩(T64 등)과 2차 범용 압축(ZSTD)을 결합해 디스크 I/O와 스토리지 비용을 최소화하는 분산 OLAP 스토리지 최적화 패턴.
* **[Perf]In-Memory Cache-based Real-time Threat Lookup & Enrichment:** 침해지표(IoC)·블랙리스트를 인메모리 데이터스토어(ClickHouse 딕셔너리·Redis 등)에 상시 로드해 두고, 실시간 로그를 무거운 디스크 JOIN 대신 O(1) 메모리 룩업으로 대조·강화하여 sub-ms로 위협을 식별하는 데이터 강화(Enrichment) 가속 패턴.
* **[Perf]Ultra-High-Speed Kernel-Layer Packet Filtering based on XDP:** 리눅스 커널이 sk_buff를 할당하기도 전, NIC 드라이버 최전선에서 eBPF 프로그램을 실행해 패킷을 즉시 Drop/Redirect/Pass 함으로써, iptables가 못 버티는 라인레이트 DDoS를 단일 코어 수십 Mpps로 막아내는 커널 네트워크 fast-path 기술(eBPF 런타임 보안 항목의 네트워크 특화 형제; DPI 등 L7 분석은 상위 레이어에 위임).
* **[Perf]nftables Architecture & Kernel VM-based Firewall Optimization:** 유저공간에서 컴파일한 방화벽 룰을 넷링크 바이트코드로 커널 경량 VM에 주입·해석하고, Set/Map 기반 O(1) 룩업과 원자적 갱신으로 iptables의 선형 탐색·리로드 한계를 극복한 차세대 리눅스 방화벽 - 단, 인터프리터 방식이라 JIT 기반 eBPF/XDP보다는 최대 처리량이 낮아 상호 보완적으로 쓰인다.
* **[Perf]High-Performance Asynchronous I/O & Direct I/O Optimization based on io_uring:** 유저·커널이 공유하는 SQ/CQ 링버퍼로 시스템 콜·컨텍스트 스위칭 없이 I/O를 완료 기반으로 제출·수거하고 O_DIRECT로 페이지 캐시를 우회해 처리량을 라인레이트에 근접시키는 리눅스 커널 비동기 I/O 인프라(5.1+) — Buffer/Kafka 배치가 정렬 청크를 공급하고, eBPF·XDP와 같은 링버퍼 계보이나 서브시스템 복잡성 탓에 CVE 다발로 Google이 Android·ChromeOS·서버에서 비활성화할 만큼 보안 공격 표면도 큼.
* **[Perf]Huge Pages / Large-Page Architecture & Kernel VM Mapping Optimization:** 4KB 대신 2MB/1GB 페이지를 매핑 단위로 써 TLB 커버리지를 512배로 넓히고 페이지 테이블 단계(PTE/PMD)를 생략해 주소 변환 병목을 없애는 저수준 메모리 최적화 — ClickHouse dictGet·인메모리 룩업의 MMU 가속기(io_uring과 상보적)이며, 향상폭은 워크로드 의존(적합 시 10~35%). THP는 스톨 탓에 always를 피하고 madvise/defer 권장, 파편화 시 연속 블록 할당 실패 위험.
* **[Perf]Large-scale Vector Search Optimization based on HNSW:** 고차원 벡터를 지수 확률로 다층 그래프에 색인하고 최상위 장거리 간선에서 탐욕 라우팅→계층 하강으로 근사 최근접 이웃을 O(log N)에 찾는 벡터 DB 표준 인덱스 — IVF 대비 recall·속도가 우수하고 고차원에 견고하나, 그래프를 전부 RAM에 상주(PQ/DiskANN·Huge Pages로 완화)하고 삽입은 증분 가능해도 삭제는 tombstone+주기 재건축이 필요. RAG·가드레일 벡터 매칭의 검색 엔진.
* **[Perf]Semantic Routing(LLM Routing):** 쿼리의 의미·복잡도를 초경량 임베딩/분류기로 판단해 값싼 SLM·프런티어 LLM·결정론적 도구 중 최적 목적지로 트래픽을 분기하는 게이트웨이 - RouteLLM 기준 최대 85% 비용 절감(품질 95% 유지)이 실측되나, 어려운 쿼리를 소형으로 오분류하면 조용한 품질 저하가 생겨 CI 게이트 검증이 필수.
* **[Perf]eBPF-based Cloud-Native Networking(eBPF-based CNI):** iptables kube-proxy가 규칙 증가에 O(n)으로 느려지고 사이드카 프록시가 자원을 잠식하던 문제를, 커널 eBPF 맵 상수시간 조회 + Netfilter 스택 우회 + IP 대신 라벨 아이덴티티 정책으로 푼 차세대 CNI.
* **[Perf]Context Caching:** 자주 사용되는 대규모 입력 데이터를 미리 연산하여 서버에 저장해두고, 이후 요청 시 재사용함으로써 AI의 응답 속도를 높이고 비용을 낮추는 기술
* **[Perf]SIMD-Accelerated Multiple Pattern Matching:** 수만 개의 패턴을 하나의 통합 자료구조로 묶고 CPU의 SIMD 벡터 연산으로 동시에 대조하여, 데이터 스트림을 단 한 번만 훑는 것만으로 모든 패턴을 기가비트급 속도로 찾아내는 고성능 다중 패턴 매칭 기법(대표 구현: Aho-Corasick 계열, bitap, DPDK ACL, Hyperscan/Vectorscan)
* **[Perf]Data Lake-Driven Real-Time Threat Alerting & Webhook Integration:** 위협을 탐지한 데이터 레이크가 외부 폴링(Polling)을 기다리지 않고 직접 SOAR·방화벽 API로 JSON 페이로드를 웹훅(Webhook) 푸시하여, 탐지 즉시 해커를 차단하는 이벤트 구동형 보안 자동화 아키텍처


### 2. Artificial Intelligence(AI 지능 및 시스템)
* **ANI → AGI → ASI:** AI 지능의 단계적 정의와 미래 발전 가능성.(Levels of AGI: Google DeepMind 및 OpenAI의 AGI 도달 로드맵 분석.)
* **MCP(Model Context Protocol):** AI와 데이터를 잇는 표준화된 '조립식' 통로.
* **Ontology:** 기계가 이해하는 지식 지도와 시맨틱 관계의 정의.
* **GNN(Graph Neural Networks):** 점과 선으로 연결된 그래프 구조의 데이터를 분석하여 노드 간의 복잡한 관계와 맥락을 파악하는 AI 모델.
* **RAG(Retrieval-Augmented Generation):** AI가 내부 지식에만 의존하지 않고 외부 문서를 실시간 검색하여 답변의 정확도와 최신성을 높이는 기술
* **Active Learning:** AI가 판단하기 어려운 데이터를 스스로 골라 사람에게 질문함으로써, 적은 데이터로도 빠르게 똑똑해지는 전략적 학습 기법
* **GraphRAG:** 텍스트를 그래프 구조로 변환하여 데이터 간의 복잡한 연결 고리를 파악하고, 전체적인 맥락을 요약할 수 있는 고도화된 RAG 기술
* **Self-RAG:** AI가 검색의 필요성부터 검색된 문서의 유용성, 답변의 정확성까지 전 과정을 스스로 평가하여 품질을 높이는 지능형 RAG 기술
* **Agentic Workflow:** AI에게 단일 프롬프트로 완벽한 결과를 요구하는 대신(Zero-shot), '계획-실행-평가-수정'의 과정을 거쳐 복잡한 업무를 자율적으로 완수하게 만드는 작업 설계 방식
* **Agentic RAG:** AI가 한 번의 검색에 의존하지 않고 스스로 질문을 분석해 최적의 DB나 도구를 반복적으로 호출하며 복잡한 문제의 답을 찾아내는 능동형 검색 증강 생성 아키텍처 ※ Self-Correcting RAG 편입
* **Multi-Agent System:** 각기 다른 전문성과 도구를 가진 여러 AI 에이전트가 상호 작용(협력, 경쟁, 검토)하여, 단일 AI로는 해결하기 어려운 복잡한 문제를 풀어내는 협업 아키텍처
* **Consensus for AI Agents:** 멀티 에이전트 시스템에서 서로 다른 분석 결과를 내놓는 에이전트들의 의견을 조율하여, 오탐과 환각이 최소화된 최종 결론을 도출하는 의사결정 체계
* **Agentic AI:** 단순한 텍스트 답변을 넘어, AI가 스스로 목표를 세우고 외부 도구(API, 검색 등)를 활용해 시행착오를 거치며 복잡한 실무를 자율적으로 완수하는 능동형 인공지능 시스템 ※ AI Agents 통합
* **On-Device AI:** 인터넷 연결이나 외부 클라우드 서버 연동 없이, 스마트폰이나 PC 내부의 NPU 칩과 경량화된 AI 모델을 통해 기기 자체적으로 인공지능 연산을 처리하는 기술
* **[Perf]Speculative Decoding:** 작고 빠른 '초안 모델'이 여러 단어를 선제적으로 예측하고, 무겁고 똑똑한 '메인 모델'이 이를 병렬 연산으로 한 번에 검증 및 승인하여, 텍스트 품질 저하 없이 답변 생성 속도(Latency)를 2~3배 끌어올리는 추론 최적화 기술
* **[Privacy]Synthetic Data:** AI 알고리즘이 원본 데이터의 통계적 패턴을 학습하여 실제 사람의 정보(PII) 없이 무한대로 찍어내는 인공 데이터로, 데이터 기근과 저작권·프라이버시 문제를 동시에 해결하는 기술 ※ DP 합성 데이터 편입
* **[Privacy]Machine Unlearning:** AI 모델을 처음부터 다시 학습시키는 막대한 비용 없이, 모델 가중치에 깃든 특정 데이터(개인정보, 저작권, 악성 데이터)의 영향력만을 수학적으로 도려내어 지우는 기술
* **AI Agent Memory Architecture:** 상태가 없는(Stateless) LLM에 인간의 인지 구조를 모방한 단기(컨텍스트 윈도우) 및 장기(외부 DB) 저장소를 결합하여, 에이전트가 과거의 문맥을 기억하고 연속적인 자율 워크플로우를 수행하도록 지원하는 시스템 구조
* **Harness Engineering:** AI 에이전트가 허용된 권한 안에서 복잡한 업무를 끝까지 안전·안정적으로 완수하도록, 모델을 둘러싼 실행·제어 런타임(컨텍스트 공급·출력 검증·상태 체크포인트·도구 오케스트레이션·HITL 승인)을 설계하는 기술 - "모델은 교체 가능한 부품, 하네스가 제품"이라는 2026년 에이전트 신뢰성 엔지니어링의 핵심.
* **Compound AI Systems:** 하나의 거대 모델에 의존하는 대신 특화된 여러 컴포넌트(소형 모델·검색기·검증기·도구)를 라우팅·오케스트레이션으로 엮어, 파라미터 크기가 아닌 시스템 구조로 비용 대비 성능·신뢰성을 끌어올리는 AI 아키텍처 패턴(RAG·에이전트 워크플로가 모두 이 범주).
* **[Perf]Test-Time Training(TTT):** 추론 시점에 입력 문맥 자체를 학습 데이터로 삼아 모델(또는 TTT 레이어)의 가중치를 자가지도 경사하강으로 실시간 갱신함으로써, KV 캐시 없이 초장문을 상수 시간(O(1))으로 처리하는 트랜스포머 대안 시퀀스 아키텍처(테스트 타임 컴퓨트와 달리 가중치를 실제로 업데이트)
* **[Perf]Linear Attention–based Linear Transformers:** 표준 어텐션의 O(N²) 병목을, Softmax를 커널 특징맵으로 대체하고 곱셈 순서를 바꿔(결합법칙) N×N 행렬 없이 O(N)으로 낮춘 아키텍처. KV 캐시 없이 O(1) 추론으로 초장문(1M+)을 처리하나, 정확한 장거리 인출(recall)이 약해 실무에선 풀 어텐션과 섞는 하이브리드가 표준(Mamba·RWKV·TTT와 같은 선형-복잡도 패밀리)
* **[Perf]Mixture-of-Depths(MoD):** 트랜스포머의 각 레이어에서 라우터가 상위 k개 중요 토큰만 무거운 연산(Attention+MLP)에 태우고 나머지는 잔차 연결로 스킵하게 하여, 고정된 연산 예산 안에서 토큰별로 '깊이'를 다르게 주는 조건부 연산 아키텍처(동일 성능에 forward FLOPs↓·샘플링 ~50%↑; MoE의 '넓이 희소성'에 대응하는 '깊이 희소성', 둘을 합치면 MoDE) ※ 중복 항목 통합
* **Agentic Self-Correction:** 에이전트가 실행 오류·테스트 실패·도구 반환 같은 외부 검증 신호를 되먹여 스스로 논리·코드를 교정하는 폐쇄 루프 기술. 순수 '자기 반성'은 자기확증 편향으로 한계가 크고(동일 주장을 외부 역할로 재라벨링하면 수정률 23~93%p↑), 외부 진실원 접지 + PRM 단계 채점이 핵심 - Self-Refine(내재적)의 상위 개념이며 무한 루프 방지는 Harness가 담당. ※ Self-Refine 편입
* **[Perf]Low-Rank Adaptation with Gradient Approximation(LoRA-GA):** 바닐라 LoRA가 무작위(A)·0(B)으로 출발해 풀 파인튜닝보다 느리게 수렴하던 문제를, 학습 전 추정한 그레이디언트 행렬의 SVD 특이벡터로 어댑터를 초기화해 첫 스텝부터 풀 FT 방향과 정렬시킴으로써 풀 FT급 수렴·성능을 내는 LoRA 초기화 기법(구조 변경 없이 시작 가중치만 교체; 사전 SVD 오버헤드·데이터 품질 의존이 트레이드오프).
* **[Perf]KV Cache Compression & Eviction:** 장문 컨텍스트에서 VRAM을 독점하는 Key/Value 캐시를, 중요 토큰만 남기는 압출(H2O·StreamingLLM)·저비트 양자화(INT4)·잠재공간 컴팩션(Attention Matching)으로 줄여 OOM을 막고 처리량을 수 배~11.8배 끌어올리는 추론 최적화 기술(Context Caching의 재사용·Linear Attention/TTT의 KV 제거와 대비되는 '압축' 계열; 추론 모델은 과압축에 취약).
* **Chain-of-Thought(CoT):** LLM이 최종 답 전에 중간 추론을 단계별로 생성하게 유도해 복잡 추론 정답률을 높이는 기법(Zero/Few-shot·Self-Consistency로 구현, o1·R1은 RL로 내재화). 재학습 없이 프롬프트만으로 적용 가능하나 토큰 비용↑·초기 오류 전파·보이는 추론이 실제 계산과 어긋날 수 있는 충실성 한계가 있음 - Self-Consistency→CaTS의 뿌리이며 Speculative Decoding·KV 압축이 그 비용을 완화.
* **[Gov]Loop Engineering:** 프롬프트를 사람이 매번 주는 대신, 목표·도구·제약을 주면 에이전트가 검증 가능한 정지 조건을 만족할 때까지 스스로 반복하도록 그 반복 제어 구조를 설계하는 기술(2026년 Claude Code에서 확산) - 하네스 엔지니어링(환경)과 보완, 자기교정(in-loop 메커니즘)의 상위 아키텍처이며, 정지 조건·예산 상한을 못 걸면 무한 비용 루프(loopmaxxing) 위험.
* **[Perf]Many-Shot In-Context Learning(Many-Shot ICL):** 가중치 업데이트 없이 프롬프트에 수백~수천 개 예시를 넣어 추론 시점에 태스크를 학습시키는 기법(arXiv:2404.11018) - 롱컨텍스트+프롬프트 캐싱으로 실용화되어 데이터 희소 분류/추출에선 파인튜닝에 필적하고 사전학습 편향을 극복하나, 개방형 생성엔 효과가 작고 매 쿼리가 긴 프롬프트 비용을 치른다(캐싱으로 ~90% 완화).
* **[Perf]Speculative RAG:** Speculative Decoding의 draft-verify 발상을 RAG에 이식해, 소형 전문 모델이 문서 서브셋별 답변 초안을 병렬 생성하고 대형 범용 모델이 자가 일관성·반성 점수로 한 번에 검증·선택하는 프레임워크(Google·UCSD, ICLR 2025) — prefill을 없애 지연을 절반가량 줄이고 정확도를 높이나, 토큰 분포를 보존하는 스펙 디코딩과 달리 무손실이 아니며 초안 품질에 의존.
* **Tree of Thoughts(ToT):** AI가 한 길로만 추론하는 CoT와 달리 갈림길마다 여러 가설을 만들어 스스로 채점하고 가망 없는 가지는 쳐내며 막히면 되돌아가는 트리 탐색 추론법(Yao et al., NeurIPS 2023) — 계획·백트래킹이 필요한 난제(Game of 24 4%→74%)에서 강력하나 수십~수백 번의 호출로 비싸고 중간 단계 자가 채점이 정확해야 성립.
* **[Perf]Reward-Guided Collaborative Test-Time Compute(RTTC):** 사전학습 보상 모델이 쿼리마다 "무적응·RAG·TTT" 중 최적 적응 전략을 골라 불필요한 연산 없이 정확도를 높이는 테스트타임 프레임워크(EMNLP 2025).
* **[Perf]Linear State Space Models(LSSM, Mamba):** 제어이론의 상태공간을 시퀀스 모델링에 이식해 과거를 고정 크기 상태에 압축하고 학습은 병렬(S4 컨볼루션/Mamba 선택적 스캔/Mamba-2 구조화 matmul), 추론은 상태 하나로 O(N)·일정 지연·KV 캐시 없이 처리하는 트랜스포머 대안— 초장문·DNA·오디오에 강하나 고정 상태 탓에 정확 인출·복사가 약해(arXiv:2402.01032) 하이브리드가 선호됨.
* **[Perf]Sparse Mixture of Experts(Sparse MoE):** 레이어를 여러 전문가로 나눠 토큰마다 라우터가 소수(Top-k)만 깨우는 아키텍처로, 전체 지식량(총 파라미터)은 키우되 연산량은 활성 파라미터로 고정해 초거대 모델을 저비용으로 구동(Mixtral·DBRX·DeepSeek-V3·Grok-1) — 단 모든 전문가를 VRAM에 올려야 하고 로드 밸런싱이 무너지면 전문가 붕괴가 발생.
* **[Perf]Direct Preference Optimization(DPO):** "A가 B보다 낫다"는 선호 쌍만으로 RLHF 목적함수를 단순 분류 손실로 풀어(언어 모델=암묵적 보상 모델) 보상 모델·PPO 없이 안정·저비용으로 정렬하는 기법.
* **Large Reasoning Models(LRMs):** 답 전에 긴 내부 사고(long CoT)로 검증·역추적·자기수정하며 테스트타임 연산을 늘려 수학·코딩·논리를 푸는 모델 패러다임(o1·R1) — 대표 방식은 외부 트리탐색+PRM이 아니라 순수 RL(GRPO)로 긴 CoT를 내재화한 것(R1은 MCTS·PRM 미사용).
* **In-Context Reinforcement Learning(ICRL):** 가중치 갱신 없이 프롬프트에 (응답+스칼라 보상)을 누적하면 LLM이 라운드가 쌓일수록 스스로 성능을 높이는 창발적 테스트타임 RL(Reward Is Enough, arXiv:2506.06303, ICLR 2026) — 훈련은 무비용이나 다중 라운드·긴 컨텍스트로 추론 비용·지연이 큼.
* **[AI-Sec]Reinforcement Learning from AI Feedback(RLAIF):** 인간 라벨러 대신 원칙(헌법)을 쥔 평가자 AI가 선호·보상을 매겨 PPO/DPO로 정렬하는 훈련법(원전=Anthropic CAI 2022, RLHF와 성능 비등—Google 2023).
* **[AI-Sec]Representation Engineering(RepE):** 가중치·입력을 건드리지 않고 추론 중 내부 활성화에서 개념 방향을 읽어(RepReading) 벡터를 가감(RepControl)해 정직성·무해성으로 조종하는 하향식 투명성·제어 기법(CAIS, arXiv:2310.01405).
* **[Perf]Test-Time Scaling Laws(TTSL):** 추론 시점에 연산(샘플링·탐색)을 늘리면 성능이 예측 가능한 곡선으로 오른다는 경험 법칙. ※ CaTS 편입
* **[Perf]1-bit LLMs(BitNet b1.58):** 훈련 시점부터 가중치를 {-1,0,+1} 3진으로 제약해 행렬 곱셈을 정수 덧셈/뺄셈으로 바꾼 네이티브 1비트 LLM(MS, arXiv:2402.17764). ※ 중복 항목 통합
* **V-JEPA 2(Video Joint Embedding Predictive Architecture 2):** 픽셀을 복원하지 않고 미래 프레임의 잠재 표현만 예측해 물리 역학을 배우는 자기지도 비디오 세계모델(Meta, arXiv:2506.09985).
* **Liquid Foundation Model(LFM):** 기존 트랜스포머(Transformer) 모델과 달리, 생물학적 신경망에서 영감을 받은 미분방정식을 활용해 뉴런의 상태를 시간에 따라 연속적으로 변화시키고, 적은 컴퓨팅 자원으로도 학습과 추론을 계속하는 것이 특징인 차세대 인공지능 모델.
* **[Perf]Discrete Diffusion LLM(dLLM):** 다음 토큰을 순차 예측하는 AR 대신 [MASK]로 덮인 문장을 반복 디노이징해 완성하는 생성 패러다임 — 양방향 문맥으로 임의 위치 삽입(코드 편집) 에 강하고 스텝 수로 품질↔속도를 조절.
* **Sparse Autoencoders(SAEs):** LLM의 얽힌 활성화를 희소 제약(L1/Top-K)으로 확장·복원해 단의적 특징으로 분해하는 해석 도구.
* **[Perf]Reinforcement Learning with Verifiable Rewards(RLVR):** 사람·AI 판정 대신 기계가 정답을 확정할 수 있는 신호(테스트 통과·수학 정답) 로 보상을 주어 LLM의 추론을 훈련하는 패러다임(DeepSeekMath·Tülu 3 유래, DeepSeek-R1이 대표 성공).
* **[Perf]Process Reward Models(PRMs):** 최종 정답만 채점하는 ORM이 엉터리 논리로 정답을 맞히는 보상 해킹에 취약하다는 진단에서 나온, 중간 추론 단계를 개별 채점하는 크리틱 모델(Lightman 2023, PRM800K).
* **Diffusion Forcing:** 기존 LLM의 '다음 토큰 예측'과 디퓨전 모델의 '전체 시퀀스 확산'을 결합하기 위해, 각 프레임마다 독립적인 노이즈 레벨을 부여하여 로보틱스와 비디오 영역에서 장기 궤적을 붕괴 없이 유연하게 생성하는 새로운 훈련 패러다임.
* **World Models & Spatial Intelligence:** 텍스트·2D 패턴 모방을 넘어 3D 기하와 물리적 인과를 인지·시뮬레이션하는 역량(공간 지능)과 그 구현체(세계 모델/WFM).


### 3. Security & Trust(보안 및 신뢰성)
* **Agentic AI Security:** 자율 행동 에이전트를 위한 권한 통제 및 가드레일 설계.
* **OSINT(Shodan):** 인터넷 노출 자산 탐색과 위협 인텔리전스 활용.
* **Adaptive Security:** AI가 공격 패턴을 실시간으로 분석하여 방어 전략을 스스로 수정하는 지능형 보안 아키텍처.
* **[AI-Sec]Contextual Isolation:** 서로 다른 권한을 가진 데이터가 AI 내부에서 섞이지 않도록 분리하여 간접 프롬프트 주입과 정보 유출을 차단하는 기술.
* **[Privacy]Differential Privacy:** 데이터 분석 결과에 무작위 노이즈를 추가하여 개별 데이터의 포함 여부를 숨기면서도 전체 통계는 보존하는 프라이버시 보호 기술.
* **[Privacy]Federated Learning:** 데이터를 중앙 서버로 수집하지 않고, 각 기기에서 개별 학습한 결과물(가중치)만 모아 전체 모델을 진화시키는 개인정보 보호 기술.
* **[AI-Sec]Adversarial Machine Learning:** AI 모델의 수학적 취약점을 이용해 입력 데이터를 미세하게 변조함으로써 AI의 오작동을 유도하거나 정보를 탈취하는 공격 및 방어 기술.
* **Zero Trust Architecture:** 네트워크 위치와 관계없이 모든 접근 요청을 매번 검증하고, 최소한의 권한만 부여하여 내부 위협 확산을 원천 차단하는 보안 모델
* **[AI-Sec]Prompt Injection:** 악의적인 자연어 입력을 통해 LLM의 시스템 지침을 무력화하고 모델의 행동을 통제하는 AI 특화 사이버 공격 ※ Indirect Prompt Injection 편입
* **[AI-Sec]AI Red Teaming:** 보안 전문가가 공격자의 시각에서 AI 모델을 고의로 공격하여, 프롬프트 주입 취약점이나 민감 정보 유출 등의 결함을 사전에 찾아내는 평가 과정 ※ Agentic AI Red Teaming 편입
* **[AI-Sec]AI Guardrails:** AI 시스템이 안전하고 윤리적인 범위 내에서만 동작하도록 사용자 프롬프트와 AI의 답변을 실시간으로 감시하고 제어하는 보안 통제선
* **[AI-Sec]Adversarial Training:** 모델을 속이도록 설계된 적대적 예제(Adversarial Examples)를 학습 과정에 고의로 주입하여, 공격에 대한 내성을 기르는 능동적 방어 기법
* **[Privacy]Model Inversion Attack:** 해커가 AI 모델이 반환하는 결과값(확률, 점수)을 수학적으로 역산하여, 모델 학습에 사용되었던 민감한 원본 데이터(얼굴 사진, 의료 기록 등)를 거꾸로 빼내는 AI 특화 정보 유출 공격
* **[Privacy]PII Redaction & Masking:** AI 모델에 데이터를 입력하거나 출력하기 전, 이름·연락처·금융 정보 등 민감한 개인 식별 정보(PII)를 자동으로 탐지하여 삭제하거나 별표(***) 등으로 가려주는 데이터 프라이버시 보호 기술
* **[AI-Sec]Many-Shot Jailbreaking:** AI에게 '유해한 지시에 복종하는 가짜 대화 패턴'을 수십~수백 번 반복 주입하여, AI가 스스로 안전 필터를 망각하고 해커의 악의적 명령을 따르도록 세뇌하는 최신 탈옥 기법
* **[AI-Sec]LLM Side-Channel Attack:** AI의 답변 내용이 아니라 토큰 생성 시간, 캐시 적중률, 암호화된 네트워크 패킷의 크기 등 시스템 동작 시 발생하는 물리적 징후를 분석하여 내부 기밀 데이터나 다른 사용자의 프롬프트를 유추해 내는 우회 공격 기법
* **[Privacy]Post-Quantum Cryptography(PQC):** 양자 컴퓨터의 연산 능력으로도 풀기 어려운 복잡한 다차원 수학 난제(격자 문제 등)를 활용하여, 기존의 소인수분해 기반 암호(RSA)를 대체하는 차세대 소프트웨어 암호 기술
* **[Privacy]Homomorphic Encryption:** 데이터를 복호화하지 않고 암호화된 텍스트 상태 그대로 사칙연산과 AI 추론을 수행하여, 데이터 유출 가능성을 원천 차단하는 수학적 암호 기술
* **[AI-Sec]Data Poisoning:** AI 모델이 학습하는 데이터셋에 악성 데이터를 몰래 섞어 넣어, 모델 전체의 예측 성능을 망가뜨리거나 해커가 원하는 특정 조건(트리거)에서만 오작동하도록 세뇌하는 업스트림(Upstream) 공격 기법
* **[AI-Sec]Context Overflow:** AI 모델이 처리할 수 있는 최대 문맥 창(Context Window) 이상의 쓰레기 데이터를 고의로 주입하여, AI가 가장 중요한 '초기 안전 시스템 지침'을 메모리에서 지워버리도록 유도하는 밀어내기 해킹 기법
* **[AI-Sec]Context Poisoning:** AI가 실시간으로 검색해 읽어들이는 외부 데이터베이스나 문서에 교묘한 거짓 정보를 심어두어, AI가 사용자에게 잘못된 답변을 진실처럼 내뱉도록 유도하는 지식 오염 공격
* **[AI-Sec]Self-Healing AI Security System:** 대규모 인프라 로그를 AI가 실시간 분석하여 보안 위협이나 오류를 탐지하고, 관리자 개입 없이 스스로 감염된 노드를 격리하거나 정상 코드로 롤백하여 시스템 가용성과 무결성을 사수하는 지능형 방어 시스템 ※ Self-Healing Security 통합
* **[AI-Sec]Agentic Security Orchestration:** 정해진 시나리오(Playbook)에 얽매이지 않고, AI 에이전트가 위협 상황을 스스로 분석하고 필요한 보안 솔루션(도구)을 자율적으로 호출하여 대응 체계를 지휘하는 차세대 보안 운영 아키텍처 ※ MASO 편입
* **[AI-Sec]Semantic Guardrails:** 단순한 금지어 필터링을 넘어, 사용자의 질문을 다차원 벡터로 변환해 '숨은 의미와 의도'를 파악함으로써 동의어나 돌려 말하기를 통한 우회 해킹(Jailbreak)을 원천 차단하는 지능형 보안 통제 기술
* **[AI-Sec]Risk-Adaptive Access Control(RADAC):** 고정된 신분(ID/비밀번호)에만 의존하지 않고 사용자의 접속 위치, 기기 상태, 행동 패턴 등 실시간 상황을 분석해 위험도를 계산한 뒤, 그에 맞춰 접근 허용/추가 인증/차단을 동적으로 결정하는 차세대 접근 제어 모델
* **[Privacy]Zero-Knowledge Proof:** 자신의 비밀번호나 개인정보 원본을 상대방이나 서버에 전혀 보여주지 않고도, 내가 그 정보를 소유하고 있다는 사실만을 수학적으로 완벽하게 증명해 내는 차세대 암호 기술
* **[Privacy]Zero-Knowledge ML:** 사용자의 입력 데이터나 기업의 AI 모델 구조(가중치)를 외부에 전혀 공개하지 않고도, "AI가 특정 데이터를 가지고 조작 없이 올바르게 연산했다"는 사실을 수학적 증명서(zk-Proof)로 발급하여 신뢰를 보장하는 기술
* **[AI-Sec]AI Agent Guardrails:** AI 에이전트가 환각이나 오류로 인해 치명적인 시스템 명령어(DB 삭제, 잘못된 결제 등)를 자율적으로 실행하는 것을 막기 위해, 도구 사용 권한을 제한하고 위험 작업 전 인간의 승인을 강제하는 실행 환경 보호 체계
* **[AI-Sec]Agentic AI SOC:** 사전에 정의된 플레이북(Playbook)에 의존하던 기존 SOAR 시스템을 넘어, AI 에이전트가 자율적으로 방대한 보안 로그를 검색·추론하여 위협을 식별하고 방어 조치까지 수행하는 차세대 보안 관제 인프라
* **[AI-Sec]Agentic Authorization:** 에이전트에게 수명이 긴 마스터 API 키를 주는 대신, 특정 워크플로우 단계에서 꼭 필요한 권한(토큰)만을 실시간으로 쪼개어 발급하고 검증하여 에이전트 탈취 시의 피해를 최소화하는 보안 아키텍처 ※ Agentic Zero Trust 통합
* **[AI-Sec]Adversarial Attacks:** 사람의 눈에는 인지되지 않는 치밀하게 계산된 수학적 노이즈를 데이터에 덧씌워, AI 모델이 완전히 엉뚱한 예측(오분류)을 하도록 속이는 알고리즘 해킹 기법
* **[AI-Sec]AI Security Guardrails:** 대화형 AI 모델의 입력(프롬프트)과 출력(답변) 패킷을 실시간으로 분석하여, 악의적인 해킹 시도를 차단하고 기업의 기밀 데이터 유출을 막아내는 AI 전용 보안 통제 시스템
* **[Privacy]Mixnet:** 인터넷 트래픽을 다중으로 암호화한 뒤 여러 노드를 거치며 의도적으로 지연시키고 가짜 노이즈 패킷과 함께 섞어(Mix), 송수신자의 메타데이터를 고도화된 AI 추적이나 글로벌 감시망으로부터 완벽하게 숨기는 프라이버시 네트워크 인프라
* **[Privacy]Sphinx Packet Format:** 노드를 거칠 때마다 암호 껍질이 벗겨져 패킷 크기가 줄어드는 기존 라우팅의 약점을 극복하기 위해, 벗겨진 만큼 공유 비밀키 기반의 결정론적 패딩을 채워 넣어 통신 전 과정에서 패킷 크기를 100% 동일하게 유지하는 최고 수준의 프라이버시 메시지 포맷
* **[Privacy]Wide Block Cipher(LIONESS):** 데이터를 작게 쪼개지 않고 패킷 전체를 하나의 거대한 블록으로 묶어 4번에 걸쳐 암호화함으로써, 단 1비트의 조작만 발생해도 데이터 전체를 완전히 파괴하여 해커의 꼬리표(Tag) 추적을 막는 스핑크스 패킷의 핵심 암호학 엔진
* **[Perf]Context-Aware Dynamic SOAR Playbook & Exception Handling:** 기계적인 룰 기반 차단으로 인한 비즈니스 장애를 막기 위해, 보안 경보 발생 시 인프라 상태와 비즈니스 중요도(컨텍스트)를 실시간 평가해 방어 워크플로우를 컨텍스트에 따라 동적으로 수정·우회(예외 처리)시키는 지능형 보안 자동화(SOAR) 기술
* **Microsegmentation-based Host & Identity Dynamic Isolation:** IP 주소 대신 호스트의 메타데이터 태그와 계정 신원을 기준으로 네트워크를 세포 단위로 잘게 쪼개어 통제하다가, 이상 징후 감지 시 SOAR와 연동해 감염된 호스트/계정을 실시간 차단·격리하는 제로 트러스트 핵심 인프라 기술
* **[Perf]eBPF-based Kernel-Level Runtime Security:** 리눅스 커널 소스 수정이나 시스템 재부팅 없이 커널 내부 샌드박스에서 검증된 보안 로직을 실행해, 시스템 콜·네트워크·프로세스 행위를 최소 오버헤드로 실시간 수집(텔레메트리)하고 즉각 차단(동적 제어)하는 무중단 런타임 보안 기술 (대표 응용: CWPP)
* **[Perf]Sequence-based Threat Hunting:** 단일 보안 알람의 한계를 극복하기 위해, 대용량 로그 데이터 레이크에서 해커의 [초기 침투 → 권한 상승 → 데이터 유출]로 이어지는 다단계 공격 발자취를 시간 순서대로 추적하여 지능형 지속 위협(APT)을 솎아내는 보안 분석 기술
* **[Perf]Bitmask-based Threat Scoring:** 해커의 탐지 우회를 위한 비순차적(Out-of-Order) 공격을 방어하기 위해, 개별 보안 이벤트를 이진수 비트(Bit)에 매핑하고 초고속 비트 논리합(OR) 연산과 가중치를 결합해 유연하고 빠르게 위험도를 산출하는 행위 기반 탐지 기술(엄격한 순서가 필요하면 windowFunnel과 하이브리드)
* **[Perf]Next-Gen WAF Inspection Engine Optimization & Resilience Architecture:** 정규식 되추적(ReDoS)으로 대표되는 알고리즘 복잡도 공격에 WAF·API 게이트웨이가 무너지지 않도록, 되추적 없는 선형시간 엔진(RE2)·룰 정적 분석·연산 예산·엔진 격리로 검사 엔진을 재설계한 복원력 아키텍처(고속 처리량 축인 SIMD 다중 패턴 매칭 항목과 상호 보완).
* **[Privacy]Contextual Integrity(CI):** 프라이버시를 '특정 사회적 맥락에서 정보 흐름이 적절한가'로 정의한 니센바움 이론(2004/2010)을, 에이전트가 도구 호출 전 5대 파라미터로 추론(CoT)하고 RL로 내재화(CI-RL)하도록 적용해, PII 마스킹을 넘어 맥락상 유출을 저감하면서 작업 완성도(Utility)를 유지하는 AI 프라이버시 거버넌스 프레임워크.
* **[AI-Sec]LLM Guardrail Framework for Input/Output Security & Policy Enforcement:** 사용자와 Core LLM 사이에서 입력·대화·RAG검색·출력·실행 5단계를 실시간 검사(Colang 상태머신 + 경량 분류기 + 정규식/사실성)해 탈옥·인젝션·PII·환각을 모델 재학습 없이 차단하는 런타임 방어 프레임워크 - 프롬프트 인젝션의 방어짝이자 카탈로그 가드레일 항목군의 상위 통합 항목이며, 문자 인젝션·퍼징으로 최대 ~100% 우회되는 한계와 Over-Refusal이 상존(CI는 더 원리적 대안, 출력 검증은 Self-Correction과 중첩). ※ RAG Guardrails 편입
* **CNAPP:** 클라우드 네이티브 애플리케이션 보호를 위한 통합 플랫폼. ※ CSPM·CWPP 통합
* **[Gov]N2SF(MLS):** 국가 다층보안체계로의 전환과 망분리 완화 대응.
* **[Privacy]Confidential Computing:** 데이터가 메모리에서 연산되는 순간에도 CPU 내부의 하드웨어 보안 구역(TEE)을 통해 암호화를 유지하여, 외부의 접근을 원천 차단하는 보안 기술. ※ TEE·TEE-GPU 통합
* **[Perf]Isolation Forest-based UEBA:** 대규모 보안 로그 속에서 정상 패턴을 무겁게 학습하는 대신, 이상치(공격 행위)는 몇 번의 무작위 분할만으로도 쉽게 '고립(Isolation)'된다는 원리를 이용해 내부자 위협과 계정 도용을 선형 시간(O(n))의 초고속으로 탐지하는 AI 보안 기술 ※ EIF 편입

| **CNAPP** | 통합(Integration) | 인프라(CSPM)와 서비스(CWPP) 보안을 하나로 합친 플랫폼 ※ CSPM·CWPP 통합 |
| **N2SF** | 다층보안(MLS) | 데이터 중요도(C-S-P)에 따라 보안 벽의 높이를 조절하는 체계 |
| **MCP** | 표준화(Standard) | AI 모델이 모든 DB/도구를 즉시 쓸 수 있게 해주는 유니버셜 어댑터 |
| **AGI** | 범용성(General) | 인간의 모든 지적 작업을 수행할 수 있는 수준의 인공지능 |
| **Agentic Security** | 행위 통제(Behavioral) | 스스로 판단하고 행동하는 AI 에이전트의 권한과 가드레일 관리 |
| **Ontology** | 지식 체계화(Semantic) | AI가 데이터의 맥락을 파악하고 논리적 결론을 도출할 수 있도록 돕는 지식의 표준 모델 |
| **Adaptive Security** | 자율적 대응 | AI가 실시간으로 위협과 환경 변화를 학습하여 방어 체계를 스스로 진화시키는 능동형 보안 모델 |
| **Contextual Isolation** | 신뢰 경계(Trust Boundary) | 서로 다른 권한을 가진 데이터가 AI 내부에서 섞이지 않도록 분리하여 간접 프롬프트 주입과 정보 유출을 차단하는 기술 |
| **Differential Privacy** | 재식별 방지 | 데이터 분석 결과에 무작위 노이즈를 추가하여 개별 데이터의 포함 여부를 숨기면서도 전체 통계는 보존하는 프라이버시 보호 기술 |
| **Graph Neural Networks** | 관계 학습 | 점과 선으로 연결된 그래프 구조의 데이터를 분석하여 노드 간의 복잡한 관계와 맥락을 파악하는 AI 모델 |
| **Federated Learning** | 분산 학습 | 데이터를 중앙 서버로 수집하지 않고, 각 기기에서 개별 학습한 결과물(가중치)만 모아 전체 모델을 진화시키는 개인정보 보호 기술 |
| **Adversarial Machine Learning** | 의사결정 경계 | AI 모델의 수학적 취약점을 이용해 입력 데이터를 미세하게 변조함으로써 AI의 오작동을 유도하거나 정보를 탈취하는 공격 및 방어 기술 |
| **Zero Trust Architecture** | Never Trust, Always Verify | 네트워크 위치와 관계없이 모든 접근 요청을 매번 검증하고, 최소한의 권한만 부여하여 내부 위협 확산을 원천 차단하는 보안 모델 |
| **Context Caching** | 재사용성 | 자주 사용되는 대규모 입력 데이터를 미리 연산하여 서버에 저장해두고, 이후 요청 시 재사용함으로써 AI의 응답 속도를 높이고 비용을 낮추는 기술 |
| **RAG(Retrieval-Augmented Generation)** | 근거 기반 생성 | AI가 내부 지식에만 의존하지 않고 외부 문서를 실시간 검색하여 답변의 정확도와 최신성을 높이는 기술 |
| **GraphRAG** | 지식 그래프 | 텍스트를 그래프 구조로 변환하여 데이터 간의 복잡한 연결 고리를 파악하고, 전체적인 맥락을 요약할 수 있는 고도화된 RAG 기술 |
| **Self-RAG** | 성찰 토큰(Reflection Tokens) | AI가 검색의 필요성부터 검색된 문서의 유용성, 답변의 정확성까지 전 과정을 스스로 평가하여 품질을 높이는 지능형 RAG 기술 |
| **Active Learning** | Human-in-the-loop | AI가 판단하기 어려운 데이터를 스스로 골라 사람에게 질문함으로써, 적은 데이터로도 빠르게 똑똑해지는 전략적 학습 기법 |
| **Prompt Injection** | Jailbreak | 악의적인 자연어 입력을 통해 LLM의 시스템 지침을 무력화하고 모델의 행동을 통제하는 AI 특화 사이버 공격 ※ Indirect Prompt Injection 편입 |
| **Agentic Workflow** | Iterative Loop | AI에게 단일 프롬프트로 완벽한 결과를 요구하는 대신(Zero-shot), '계획-실행-평가-수정'의 과정을 거쳐 복잡한 업무를 자율적으로 완수하게 만드는 작업 설계 방식 |
| **Confidential Computing** | 하드웨어 격리 | 데이터가 메모리에서 연산되는 순간에도 CPU 내부의 하드웨어 보안 구역(TEE)을 통해 암호화를 유지하여, 외부의 접근을 원천 차단하는 보안 기술 ※ TEE·TEE-GPU 통합 |
| **AI Red Teaming** | 탈옥(Jailbreaking) | 보안 전문가가 공격자의 시각에서 AI 모델을 고의로 공격하여, 프롬프트 주입 취약점이나 민감 정보 유출 등의 결함을 사전에 찾아내는 평가 과정 ※ Agentic AI Red Teaming 편입 |
| **AI Guardrails** | 입출력 필터링 | AI 시스템이 안전하고 윤리적인 범위 내에서만 동작하도록 사용자 프롬프트와 AI의 답변을 실시간으로 감시하고 제어하는 보안 통제선 |
| **Agentic RAG** | 능동적 정보 탐색 | AI가 한 번의 검색에 의존하지 않고 스스로 질문을 분석해 최적의 데이터베이스나 도구를 반복적으로 호출하며 복잡한 문제의 답을 찾아내는 능동형 검색 증강 생성 아키텍처 ※ Self-Correcting RAG 편입 |
| **Consensus for AI Agents** | 집단 지성 | 멀티 에이전트 시스템에서 서로 다른 분석 결과를 내놓는 에이전트들의 의견을 조율하여, 오탐과 환각이 최소화된 최종 결론을 도출하는 의사결정 체계 |
| **Adversarial Training** | 모델 견고성(Robustness) | 모델을 속이도록 설계된 적대적 예제(Adversarial Examples)를 학습 과정에 고의로 주입하여, 공격에 대한 내성을 기르는 능동적 방어 기법 |
| **Model Inversion Attack** | 원본 데이터 복원(Data Reconstruction) | 해커가 AI 모델이 반환하는 결과값(확률, 점수)을 수학적으로 역산하여, 모델 학습에 사용되었던 민감한 원본 데이터(얼굴 사진, 의료 기록 등)를 거꾸로 빼내는 AI 특화 정보 유출 공격 |
| **PII Redaction & Masking** | 개체명 인식(NER) | AI 모델에 데이터를 입력하거나 출력하기 전, 이름·연락처·금융 정보 등 민감한 개인 식별 정보(PII)를 자동으로 탐지하여 삭제하거나 별표(***) 등으로 가려주는 데이터 프라이버시 보호 기술 |
| **Many-Shot Jailbreaking** | 긴 문맥 창(Long Context Window) | AI에게 '유해한 지시에 복종하는 가짜 대화 패턴'을 수십~수백 번 반복 주입하여, AI가 스스로 안전 필터를 망각하고 해커의 악의적 명령을 따르도록 세뇌하는 최신 탈옥 기법 |
| **LLM Side-Channel Attack** | 타이밍 공격(Timing Attack) | AI의 답변 내용이 아니라 토큰 생성 시간, 캐시 적중률, 암호화된 네트워크 패킷의 크기 등 시스템 동작 시 발생하는 물리적 징후를 분석하여 내부 기밀 데이터나 다른 사용자의 프롬프트를 유추해 내는 우회 공격 기법 |
| **Post-Quantum Cryptography(PQC)** | 격자 기반 암호(Lattice-based) | 양자 컴퓨터의 연산 능력으로도 풀기 어려운 복잡한 다차원 수학 난제(격자 문제 등)를 활용하여, 기존의 소인수분해 기반 암호(RSA)를 대체하는 차세대 소프트웨어 암호 기술 |
| **Agentic AI** | 주체성(Agency) | 단순한 텍스트 답변을 넘어, AI가 스스로 목표를 세우고 외부 도구(API, 검색 등)를 활용해 시행착오를 거치며 복잡한 실무를 자율적으로 완수하는 능동형 인공지능 시스템 ※ AI Agents 통합 |
| **Homomorphic Encryption** | 암호화 상태 연산 | 데이터를 복호화하지 않고 암호화된 텍스트 상태 그대로 사칙연산과 AI 추론을 수행하여, 데이터 유출 가능성을 원천 차단하는 수학적 암호 기술 |
| **On-Device AI** | NPU(신경망 처리 장치) | 인터넷 연결이나 외부 클라우드 서버 연동 없이, 스마트폰이나 PC 내부의 NPU 칩과 경량화된 AI 모델을 통해 기기 자체적으로 인공지능 연산을 처리하는 기술 |
| **Speculative Decoding** | 무손실 가속(Lossless Acceleration) | 작고 빠른 '초안 모델'이 여러 단어를 선제적으로 예측하고, 무겁고 똑똑한 '메인 모델'이 이를 병렬 연산으로 한 번에 검증 및 승인하여, 텍스트 품질 저하 없이 답변 생성 속도(Latency)를 2~3배 끌어올리는 추론 최적화 기술 |
| **Data Poisoning** | 훈련 데이터 오염 | AI 모델이 학습하는 데이터셋에 악성 데이터를 몰래 섞어 넣어, 모델 전체의 예측 성능을 망가뜨리거나 해커가 원하는 특정 조건(트리거)에서만 오작동하도록 세뇌하는 업스트림(Upstream) 공격 기법 |
| **Context Overflow** | 프롬프트 밀어내기(Prompt Flushing) | AI 모델이 처리할 수 있는 최대 문맥 창(Context Window) 이상의 쓰레기 데이터를 고의로 주입하여, AI가 가장 중요한 '초기 안전 시스템 지침'을 메모리에서 지워버리도록 유도하는 밀어내기 해킹 기법 |
| **Context Poisoning** | 지식 기반 오염(KB Poisoning) | AI가 실시간으로 검색해 읽어들이는 외부 데이터베이스나 문서에 교묘한 거짓 정보를 심어두어, AI가 사용자에게 잘못된 답변을 진실처럼 내뱉도록 유도하는 지식 오염 공격 |
| **Self-Healing AI Security System** | 무인 방어 체계(Autonomous Defense) | 대규모 인프라 로그를 AI가 실시간 분석하여 보안 위협이나 오류를 탐지하고, 관리자 개입 없이 스스로 감염된 노드를 격리하거나 정상 코드로 롤백하여 시스템 가용성과 무결성을 사수하는 지능형 방어 시스템 ※ Self-Healing Security 통합 |
| **Agentic Security Orchestration** | 동적 대응(Dynamic Response) | 정해진 시나리오(Playbook)에 얽매이지 않고, AI 에이전트가 위협 상황을 스스로 분석하고 필요한 보안 솔루션(도구)을 자율적으로 호출하여 대응 체계를 지휘하는 차세대 보안 운영 아키텍처 ※ MASO 편입 |
| **Semantic Guardrails** | 임베딩 벡터(Vector Embedding) | 단순한 금지어 필터링을 넘어, 사용자의 질문을 다차원 벡터로 변환해 '숨은 의미와 의도'를 파악함으로써 동의어나 돌려 말하기를 통한 우회 해킹(Jailbreak)을 원천 차단하는 지능형 보안 통제 기술 |
| **Risk-Adaptive Access Control** | 동적 위험도 산출(Risk Scoring) | 고정된 신분(ID/비밀번호)에만 의존하지 않고 사용자의 접속 위치, 기기 상태, 행동 패턴 등 실시간 상황을 분석해 위험도를 계산한 뒤, 그에 맞춰 접근 허용/추가 인증/차단을 동적으로 결정하는 차세대 접근 제어 모델 |
| **Synthetic Data** | 데이터 증강(Data Augmentation) | AI 알고리즘이 원본 데이터의 통계적 패턴을 학습하여 실제 사람의 정보(PII) 없이 무한대로 찍어내는 인공 데이터로, 데이터 기근과 저작권·프라이버시 문제를 동시에 해결하는 기술 ※ DP 합성 데이터 편입 |
| **Zero-Knowledge Proof** | 증명자(Prover) | 자신의 비밀번호나 개인정보 원본을 상대방이나 서버에 전혀 보여주지 않고도, 내가 그 정보를 소유하고 있다는 사실만을 수학적으로 완벽하게 증명해 내는 차세대 암호 기술 |
| **Zero-Knowledge ML** | 신뢰할 수 있는 AI | 사용자의 입력 데이터나 기업의 AI 모델 구조(가중치)를 외부에 전혀 공개하지 않고도, "AI가 특정 데이터를 가지고 조작 없이 올바르게 연산했다"는 사실을 수학적 증명서(zk-Proof)로 발급하여 신뢰를 보장하는 기술 |
| **Machine Unlearning** | 잊힐 권리(Right to be Forgotten) | AI 모델을 처음부터 다시 학습시키는 막대한 비용 없이, 모델 가중치에 깃든 특정 데이터(개인정보, 저작권, 악성 데이터)의 영향력만을 수학적으로 도려내어 지우는 기술 |
| **AI Agent Memory Architecture** | 단기/장기 메모리 | 상태가 없는(Stateless) LLM에 인간의 인지 구조를 모방한 단기(컨텍스트 윈도우) 및 장기(외부 DB) 저장소를 결합하여, 에이전트가 과거의 문맥을 기억하고 연속적인 자율 워크플로우를 수행하도록 지원하는 시스템 구조 |
| **AI Agent Guardrails** | 행동 제어(Action Control) | AI 에이전트가 환각이나 오류로 인해 치명적인 시스템 명령어(DB 삭제, 잘못된 결제 등)를 자율적으로 실행하는 것을 막기 위해, 도구 사용 권한을 제한하고 위험 작업 전 인간의 승인을 강제하는 실행 환경 보호 체계 |
| **Agentic AI SOC** | 자율 조사(Autonomous Triage) | 사전에 정의된 플레이북(Playbook)에 의존하던 기존 SOAR 시스템을 넘어, AI 에이전트가 자율적으로 방대한 보안 로그를 검색·추론하여 위협을 식별하고 방어 조치까지 수행하는 차세대 보안 관제 인프라 |

| **Sparse Mixture of Experts(Sparse MoE)** | 게이팅/라우터(Top-1/2) | 레이어를 여러 전문가로 나눠 토큰마다 라우터가 소수(Top-k)만 깨우는 아키텍처로, 전체 지식량(총 파라미터)은 키우되 연산량은 활성 파라미터로 고정해 초거대 모델을 저비용으로 구동(Mixtral·DBRX·DeepSeek-V3·Grok-1) — 단 모든 전문가를 VRAM에 올려야 하고 로드 밸런싱이 무너지면 전문가 붕괴가 발생. |
| **Direct Preference Optimization(DPO)** | RLHF 단순화(보상모델·PPO 제거) | "A가 B보다 낫다"는 선호 쌍만으로 RLHF 목적함수를 단순 분류 손실로 풀어(언어 모델=암묵적 보상 모델) 보상 모델·PPO 없이 안정·저비용으로 정렬하는 기법(Stanford, NeurIPS 2023; Zephyr가 대표 사례) — LoRA와 결합해 로컬 SLM에도 쓰이나 다양성 저하·길이 편향·오프라인 한계가 있고, 복합 추론은 검증가능 보상 RL(GRPO/DAPO)이 우세. |
| **Large Reasoning Models(LRMs)** | System 2 심사숙고 | 답 전에 긴 내부 사고(long CoT)로 검증·역추적·자기수정하며 테스트타임 연산을 늘려 수학·코딩·논리를 푸는 모델 패러다임(o1·R1) — 대표 방식은 외부 트리탐색+PRM이 아니라 순수 RL(GRPO)로 긴 CoT를 내재화한 것(R1은 MCTS·PRM 미사용). |
| **In-Context Reinforcement Learning(ICRL)** | 가중치 무갱신 | 가중치 갱신 없이 프롬프트에 (응답+스칼라 보상)을 누적하면 LLM이 라운드가 쌓일수록 스스로 성능을 높이는 창발적 테스트타임 RL(Reward Is Enough, arXiv:2506.06303, ICLR 2026) — 훈련은 무비용이나 다중 라운드·긴 컨텍스트로 추론 비용·지연이 큼. |
| **Reinforcement Learning from AI Feedback(RLAIF)** | 인간 대신 평가자 AI 피드백 | 인간 라벨러 대신 원칙(헌법)을 쥔 평가자 AI가 선호·보상을 매겨 PPO/DPO로 정렬하는 훈련법 |
| **Representation Engineering(RepE)** | 은닉 상태 조작 | 가중치·입력을 건드리지 않고 추론 중 내부 활성화에서 개념 방향을 읽어(RepReading) 벡터를 가감(RepControl)해 정직성·무해성으로 조종하는 하향식 투명성·제어 기법(CAIS, arXiv:2310.01405) — 훈련 없이 저비용으로 탈옥 강건성을 높이나(Circuit Breakers) 원천 차단은 아니며, 화이트박스(오픈웨이트) 전용이고 과도 조작 시 성능이 붕괴. 반대로 '거절 방향'을 제거하면 무수정 모델을 만드는 이중용도(abliteration). |
| **Test-Time Scaling Laws(TTSL)** | 훈련↔추론 compute 치환 | 추론 시점에 연산(샘플링·탐색)을 늘리면 성능이 예측 가능한 곡선으로 오른다는 경험 법칙 — 작은 모델+compute가 최대 ~14배 큰 모델을 능가할 수 있으나(Snell) 문제 난이도에 한정되고, Best-of-N은 로그-멱법칙으로 상승하다 포화하며 검증자 품질이 성능 천장을 정하고 메모리 병목까지 넣으면(Kinetics) 소형 모델 우위가 줄어든다. ※ CaTS 편입 |
| **1-bit LLMs(BitNet b1.58)** | 3진 가중치{-1,0,+1}(log₂3≈1.58비트) | 훈련 시점부터 가중치를 {-1,0,+1} 3진으로 제약해 행렬 곱셈을 정수 덧셈/뺄셈으로 바꾼 네이티브 1비트 LLM(MS, arXiv:2402.17764) — 동급 FP16과 성능이 대등하면서 CPU에서 2.37~6.17배 빠르고 에너지를 71.9~82.2% 절감, 100B을 단일 CPU에서 읽기 속도로 구동 가능해 폐쇄망·온디바이스에 유리. 단 사후 양자화(PTQ)로는 성립하지 않아 재학습이 필요하고 전용 스택(bitnet.cpp) 종속·상용 GPU 미최적화·툴킷 미성숙이 한계. ※ 중복 항목 통합 |
| **V-JEPA 2(Video Joint Embedding Predictive Architecture 2)** | 잠재 표현 예측(비생성·디코더 없음) | 픽셀을 복원하지 않고 미래 프레임의 잠재 표현만 예측해 물리 역학을 배우는 자기지도 비디오 세계모델(Meta, arXiv:2506.09985) — 100만 시간 영상 사전학습 + 로봇 62시간 사후학습만으로 새 환경에서 목표 이미지 기반 제로샷 조작(pick-and-place 65~80%)을 수행하고 생성형 월드모델(Cosmos) 대비 행동당 16초 vs 4분으로 훨씬 빠르나, 동영상을 생성하지 못해 미디어 용도엔 부적합하고 오차 누적·탐색공간 폭발로 계획이 단기(T=1)에 제한되며 카메라 각도에 민감. |
| **Liquid Foundation Model(LFM)** | 비트랜스포머 | 기존 트랜스포머(Transformer) 모델과 달리, 생물학적 신경망에서 영감을 받은 미분방정식을 활용해 뉴런의 상태를 시간에 따라 연속적으로 변화시키고, 적은 컴퓨팅 자원으로도 학습과 추론을 계속하는 것이 특징인 차세대 인공지능 모델. |
| **Discrete Diffusion LLM(dLLM)** | 이산 확산(D3PM·흡수 상태 [MASK]) | 다음 토큰을 순차 예측하는 AR 대신 [MASK]로 덮인 문장을 반복 디노이징해 완성하는 생성 패러다임 — 양방향 문맥으로 임의 위치 삽입(코드 편집) 에 강하고 스텝 수로 품질↔속도를 조절하며 상용 모델은 ~10배 디코딩(≈1,000 tok/s)을 보고. 단 여러 토큰을 동시에 확정하면 토큰 의존을 무시해 품질이 무너지고("New City" 오류), 양방향 어텐션 탓에 KV 캐시가 어려워 실측 속도가 AR보다 느린 경우가 흔하며 긴 추론·일반 태스크에선 최상위 AR에 미달. |
| **Sparse Autoencoders(SAEs)** | 다의성·중첩(superposition) | LLM의 얽힌 활성화를 희소 제약(L1/Top-K)으로 확장·복원해 단의적 특징으로 분해하는 해석 도구; 내부에서 무엇이 켜졌는지 보고 특정 특징을 억제해 조향·디톡스에 쓸 수 있으나, 시드마다 학습 특징이 달라 재현성이 취약하고 단순 베이스라인 대비 실효성 논란(2502.16681 ↔ 2605.31183) 이 진행 중이라 규제 감사의 단독 증거로는 부적합. |
| **Reinforcement Learning with Verifiable Rewards(RLVR)** | 보상모델→검증 함수 대체 | 사람·AI 판정 대신 기계가 정답을 확정할 수 있는 신호(테스트 통과·수학 정답) 로 보상을 주어 LLM의 추론을 훈련하는 패러다임(DeepSeekMath·Tülu 3 유래, DeepSeek-R1이 대표 성공) — 라벨링 병목을 없애고 아첨·환각형 보상 해킹을 줄이며 자기교정("Aha moment")이 창발했다는 보고가 있으나, 검증기가 못 막는 빈틈을 파고드는 새로운 보상 해킹과 "새 능력을 만드는가, 기존 성공 확률을 증폭할 뿐인가"라는 논쟁(arXiv:2503.06639)이 남아 있고 정답이 없는 개방형 생성엔 그대로 적용 불가. |
| **Process Reward Models(PRMs)** | 과정 감독(process supervision) | 최종 정답만 채점하는 ORM이 엉터리 논리로 정답을 맞히는 보상 해킹에 취약하다는 진단에서 나온, 중간 추론 단계를 개별 채점하는 크리틱 모델(Lightman 2023, PRM800K) — 오류가 처음 난 단계를 짚어 설명 가능성이 높고 MCTS·Best-of-N의 가치 함수로 탐색 효율(ORM 대비 정확도 +8%·샘플 효율 ~6배)을 올리지만, 라벨링 비용이 크고(MC 자동합성은 품질 열등) 단계 경계가 모호하며, 실제로는 최종 답 점수에 지배돼 ORM처럼 작동하거나 강한 ORM에 밀리는 사례와 교차 도메인 일반화 취약이 보고돼 ORM 베이스라인과의 비교가 필수. |
| **Diffusion Forcing** | 토큰별 독립 노이즈(per-token noise) | 큰마다 다른 노이즈 레벨을 줘 확산 모델에 인과성을 부여함으로써, AR의 가변 길이 생성과 확산의 목표 지향 샘플링 유도를 동시에 얻는 훈련 패러다임(Chen 외, NeurIPS 2024) — 훈련 길이를 넘는 장기 궤적을 붕괴 없이 연장해 로봇 제어·마인크래프트 영상에서 실증됐으나, 반복 디노이징으로 실시간성이 떨어지고 연속 도메인 최적화라 텍스트 같은 이산 데이터엔 별도 정식화(MaskFlow 등) 가 필요하며, 가변 길이 히스토리 조건화는 후속 DFoT가 보완. |
| **eBPF-based Cloud-Native Networking(eBPF-based CNI)** | kube-proxy 대체(eBPF 해시 맵·Netfilter 우회) | iptables kube-proxy가 규칙 증가에 O(n)으로 느려지고 사이드카 프록시가 자원을 잠식하던 문제를, 커널 eBPF 맵 상수시간 조회 + Netfilter 스택 우회 + IP 대신 라벨 아이덴티티 정책으로 푼 차세대 CNI(CNCF 2025 최다 사용, +47%) — IPVS(이미 O(1))보다도 스택 우회 덕에 우위로 1,000+ 서비스에서 지연 ~30~60%↓·CPU ~50%↓가 보고되며, 동일 노드는 Sockmap 직결·인그레스는 XDP_DROP으로 처리한다. |
| **World Models & Spatial Intelligence** | 3D 기하·영속성·가림·중력 | 텍스트·2D 패턴 모방을 넘어 3D 기하와 물리적 인과를 인지·시뮬레이션하는 역량(공간 지능)과 그 구현체(세계 모델/WFM) — 텍스트엔 기하·영속성 구조가 없다는 진단(Fei-Fei Li)에서 출발해, 이미지·프롬프트로 편집 가능한 3D 공간을 구성(Marble: Splat·메시 내보내기)하고 물리 기반 합성 데이터로 로봇·자율주행을 훈련(Cosmos). 단 물리는 근사 학습이라 분포 밖 상황에서 그럴듯하지만 틀릴 수 있고, Sim-to-Real 간극과 3D 연산의 큰 비용이 남아 ms급 실시간 제어엔 부적합. |
